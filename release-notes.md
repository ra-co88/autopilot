## [3.18.0](https://github.com/ra-co88/autopilot/compare/v3.20.0...v3.18.0) (2026-11-12)


###   BREAKING CHANGES

* the `sessionWorktrees` config option, the KIMIFLARE_SESSION_WORKTREES / AUTOPILOT_SESSION_WORKTREES env vars and the `/worktrees` command are gone; sessions no longer create worktrees.
* **git:** SDK, server and print/emit sessions now write code changes to a session worktree instead of the caller's checkout. Set `sessionWorktrees: false` (or `KIMIFLARE_SESSION_WORKTREES=0`) to keep the old in-place behavior.
* **hooks,lsp:** require trust before running a project's hooks or LSP servers ([#925](https://github.com/ra-co88/autopilot/issues/925))
* **ui:** `--ui ink`, `KIMIFLARE_UI=ink` and `/ui` are gone; the `--ui` option is now rejected as unknown. A saved `uiEngine` is ignored and dropped the next time the config is saved.
